# 话单与资费定义

subscriber用户编码和session会话号均按字符串保形，前导零不变。sequence是NFKC归一后的正整数，允许1至100000。start/end必须带偏移且结束晚于开始，进入规则后统一UTC；单片最长24小时。

去重键为session+sequence。同键时刻相同保留最早来源行，其余隔离；同键时刻冲突整会话隔离，避免用缺失的一片重算收费。会话必须归属同一subscriber和zone。分片序列从1连续，缺序整会话隔离。

区间使用[start,end)，相邻端点不重复。将每片区间求并集后得到有效秒，间隙不计费。有效秒除60向上取整得到整个会话计费分钟，不能对各片分别取整。费率与合计使用Decimal，CNY按会话最后一步保留两位，采用ROUND_HALF_UP。国内前三分钟每分钟0.20元、之后0.10元；漫游前三分钟1.50元、之后1.20元。

资费按zone与会话最早开始时刻匹配[start,end)中的唯一版本，会话跨版本仍保持开始时已选版本。缺失或重叠版本隔离该会话。供应商账单缺失为未知，不能当零；未出现有效话单的账单列为未匹配。

计费策略policy是运行参数，写入清单parameters，同话单同策略重跑不重复出账。whole_call（默认）整通沿用起话时刻版本；per_period把并集窗口按版本边界切成段，同版本相邻片合并为一段。两种策略都只对整通有效秒向上取整一次：per_period把计费分钟按各段秒数的最大余数法分摊，余数相同先发生的段优先，段内按该段版本阶梯计价，段金额按分ROUND_HALF_UP，会话金额为各段之和。per_period要求版本覆盖整通时长，覆盖缺口或重叠整会话隔离。策略非法或数据失败时不写入任何记录，上一版与全部分片原样保留。

空值哨兵包括空串、短横线、N/A、NULL、未知，不代入零。空文件、仅表头、全空行分别为EMPTY_FILE、HEADER_ONLY、BLANK_ROWS。所有隔离均有来源行、稳定原因码与原字段；CSV导出与页面同源。
